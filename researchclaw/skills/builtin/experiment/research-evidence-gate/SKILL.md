# 研究贡献与证据裁决（Research Evidence Gate）

## 核心规则（先执行，再参考后文）

本 Skill 用于每一项科研假设的生成、筛选、实验设计、结果解释和终止复核，尤其适用于多课题并行启动。其目的是提高真实科学信息增量和判决可靠性，不是提高 KILL 数量、制造论文、阻止一切探索或自动授权实验。

1. **先问研究价值**：如果假设完全成立，相对于最接近的现有工作，我们究竟新增了什么重要的科学认识？精确实验组合尚无人做过，不等于新机制成立；仅有现象、普通消融、排名变化或数学恒等式，不自动具备论文贡献。
2. **先验证测量，再解释科学**：数据合同、时间对齐、独立样本、动态范围、身份/恒等回放和负控制必须能够识别待测主张。实现异常、样本门不足、NaN、冻结规则未执行时，输出 INVALID/UNKNOWN，**绝不据此宣称核心命题被证伪**。
3. **先比较最简单的合理解释**：恒等、常数、单帧、标准归一化、线性模型或已知方法等基线按研究对象选择；报告相对增量而非仅报告方法总收益。基线已经解释收益时，不能声称新机制。
4. **证据绑定具体主张版本**：每次 GO/HOLD/KILL 都必须写明 claim_id、版本、实验条件、协议、实际执行字段、原始证据和反驳范围。KILL 是有作用域的判断，不是对整个研究方向的永久封杀。
5. **将科学真假、测量有效性、创新性、资源状态、论文就绪分开**。论文不可投、工程阻塞、证据不足、局部负结果和理论错误是不同事实。
6. **失败也可能有价值**：可靠的负结果、成功的测量校准、消除替代解释的对照都能增加知识。保留其资产，避免为了追求论文数事后改阈值、重用已暴露测试集或把技术 PASS 升格为科学 GO。
7. **Skill 不等于硬执行门**：不要假定被加载就会阻断任务。实际执行权限、额度、并发、发布及人审仍由真实控制器和用户授权决定；若控制器只运行在 shadow 模式，明确报告，而非宣称已强制执行。

## 工作流（对每个独立主张单独执行）

### A. 主张身份与证据快照

- 建立稳定 claim_id 与版本；记录别名、相关会议、先前状态和完整来源。相同编号不一定是相同问题；相关论文或跨会议版本也不能重复计独立成果。
- 写出一条明确的可检验陈述：对象、操纵/输入、目标测量量、条件、预期方向、最小实际重要幅度、能推翻它的结果。理论命题则写量词、假设、已知先例和反例条件。
- 标记证据等级：原始数据与代码、冻结执行记录、第三方原文、摘要转录、代理描述。缺底层材料时写 UNKNOWN，不自动沿用旧表、旧 README 或最后一句总结。
- 记录报告日期、代码/数据/模型/协议指纹及最终集曝光历史。缺少历史快照不可假装新的结果就是独立确认。

### B. 科学贡献预审：阳性也必须有价值

回答四问：
1. 目前最接近的原文、方法、数据、定理是什么？原作究竟已经证明/实验了什么，哪些只是动机？
2. 若得到预期正结果，能排除哪一个非平凡的现有解释？改变了什么理论、机制认识、可靠性边界或可复用方法？
3. 若得到负结果，我们会否获得清晰的知识约束？还是只是某个临时设置无效？
4. 主张是否依赖显然混杂的因素、普通重加权、常见 trade-off 或前人已经报告的消融？

区分 EXACT_COLLISION（精确核心已被可靠先例覆盖）、PARTIAL_OVERLAP（广义现象近似但明确残余未定）、THIN_CONTRIBUTION（有独特设置但没有足够科学增量）、NOVELTY_UNKNOWN 和 PLAUSIBLE_INCREMENT。不要把未检索到论文写成“已证明原创”，也不要把局部碰撞外推为全方向无价值。高成本扩展前优先审查真正的剩余 estimand 和对照。

### C. 仪器、协议与有效性检查

在模型大规模运行之前，检查最便宜的可否证前提：
- 数据对象、时间顺序、标签/动作语义、泄漏、训练与测试独立单位是否真实；区分软件记录时刻与物理执行时刻，区分共享场景/帧与独立确认集。
- 最小输入样例能否通过，NaN/Inf/维度/索引/离线依赖是否被检出；预先验收模型与资产，不要占用 GPU 才联网下载。
- 观测量能否变化、信号动态范围是否足够；必要的恒等重放、负控制、随机控制、oracle 与其限制是否定义清楚。
- 将**每条冻结有效性及终止条件**逐条映射到具体代码检查、结果字段、样本分母和数值判决；检查缺少任意硬门时是否返回 INVALID/UNKNOWN。哈希一致不保证逻辑实现了规则。
- 若 instrument 失败，可允许不接触最终科学端点的有限校准新版本，但不得将校准 GO 计作科学 GO。

### D. 基线、统计与因果增量

- 冻结最简单合理基线、最强相关既有基线和隔离机制所需消融。基线选择随任务变化，不强加所有领域必须三/五种子或固定效果阈值。
- 报告配对增量、分母、效应量和不确定性；区分探索、预注册确认、同数据多随机数及真正独立验证。非显著不等于证明零效应；区间精度足够时可支持对预定实际幅度的排除。
- 对机制主张检查替代解释（例如归一化改变、覆盖率、正则范围、输入错位、几何支持、模板捷径）。没有隔离替代解释则不升级为因果机制。
- 未暴露的独立单位不足时可保留探索性结果，但必须显式声明：不能把重复帧、同一场景的多对、同模型多 probe 或事后调参算作独立科学重复。

### E. 执行、止损与信息增量

- 先低成本文献/理论/CPU/仪器检查，再做必要的 GPU/大模型确认；每次扩展必须写“本轮能改变哪条不确定判断”和停止条件。
- 分开记录执行故障、真实任务失败和科学阴性；异常不能吞掉后以普通模型失败进入统计分母。
- 登记 root job、资源单位和成本来源。没有日志写 NOT_RECORDED；申请的预算不等于已耗费，模型推理调用不等于独立实验。
- 结果不支持时避免无限调参、修改主效应阈值、反复搜索相同资产、用已曝光终测集换种子制造“新验证”。
- 若问题已得到有效负结果，停的是该条件与该版本；如果设备失败、缺数据或资源停止，保留未决科学主张。

### F. 五轴裁决与状态传播

每条判决输出独立的五轴，不要让一个 KILL 标签承担所有含义：
- scientific_claim: SUPPORTED / CONTRADICTED_IN_SCOPE / INCONCLUSIVE / NOT_TESTED
- measurement_validity: VALID / INVALID / UNKNOWN
- novelty: PLAUSIBLE_INCREMENT / PARTIAL_OVERLAP / EXACT_COLLISION / THIN_CONTRIBUTION / UNKNOWN
- execution: PLANNED / ACTIVE / BLOCKED / STOPPED / ARCHIVED
- paper_readiness: NOT_READY / NEEDS_INDEPENDENT_CHECK / READY_FOR_HUMAN_AUDIT

再给出该版本的操作决定：PROCEED_MINIMAL、PROCEED_CONFIRMATION、HOLD_EVIDENCE、INVALID_MEASUREMENT、STOP_VERSION、STOP_RESOURCES、HUMAN_REVIEW。将其映射到已有 GO/HOLD/KILL 标签时，必须解释语义与范围，且不得擅自更改历史主状态或绕过授权。即使实验有效阴性，也只在冻结条件与估计目标内写 CONTRADICTED_IN_SCOPE。

### G. 下一轮全线并行启动的特别要求

“全线启动”是可以为所有候选开展并行检查与低成本研究的工作组织方式，**不是让所有项目无条件占 GPU 或自动写稿**：
1. 先生成候选清单：稳定 ID/版本/别名、证据现状、依赖、预定投入、可用资源、执行权限；缺失的旧档记 UNKNOWN。
2. 并行执行每题的 B/C/D 轻量 Gate，标注可马上开展最小试验、需补证据、只适合归档或需人工处理；先计算信息增量与可避免阻塞。
3. 只将通过相应准备条件、预算和实际运行授权的任务投入计算；任务目录、随机种子、原始结果与状态互相隔离，避免一个代理的结论被多个会议重复计产出。
4. 建立总控看板：每题何处卡住、已证何事、仍未知何事、下一最小可证伪动作、实际开销、结果可信度。科学 GO、工程 PASS 与投稿成熟度分列。
5. 允许运行中出现无 GO 的批次；禁止因论文配额而提高状态、补造实验、跳过对照或自动公开发表。

## 每次最少输出格式

采用简明中文，保留可机读标签，不只回复“GO_ARCHITECTURE”之类简码。至少给出：

- 研究主张：claim_id / version / 精确问题 / 当前有效范围
- 若阳性，将新增的科学认识与最近邻差异；若阴性，能排除什么
- 证据：路径或可访问来源、原始数据/程序位置、协议指纹和时间；无法取得写 UNKNOWN
- 测量与协议：冻结规则 → 实现检查 → 结果字段 → PASS/FAIL/UNKNOWN；有效样本单位/分母
- 基线与增量：对照、点估计、区间/不确定性、实际重要幅度、独立性与最终集曝光
- 五轴科学状态与操作决策（每轴一句中文理由），不可由旧状态直接继承
- 下一动作：最小信息增量、停止条件、成本上限、是否需要人审/运行授权
- 资产：保留的正确数学/负结果/可复用代码与明确不可声称的贡献

## 回归自测（审计自己的判决）

- 数值程序出现 NaN 或 identity replay 不一致 → INVALID_MEASUREMENT，不是核心科学命题已假。
- 原冻结要求足够有效主对象而结果数量不足，分析代码又未检查 → UNKNOWN/INVALID，不能可靠 KILL。
- 测量校准成功但主科学时序没有跑 → 测量通过、科学 NOT_TESTED、论文 NOT_READY。
- 复杂算法总收益很大但简单基线几乎复制全部收益 → 明确报告增量，不能无根据归因于复杂机制。
- 文献仅覆盖广义现象，精确剩余未作原文核验 → PARTIAL_OVERLAP，不得宣称精确问题全部占据。
- 新一轮沿用已曝光场景或测试集 → 探索性复核，不得冒充独立确认。
- 一条可靠的有界负结果 → 保留科学资产，关闭对应版本，而不是自动抹杀研究谱系。

## 边界

本 Skill 是工作方法，不会自动修改现有权限、调度器、质量门代码、发布设置或历史科研结论。首次全批启用前应对已知测量无效、有效负结果、正面校准及部分文献碰撞案例做离线回归审计，同时衡量误杀与误放。未验证执行链覆盖范围时必须报告风险，不能宣称“Skill 已安装”就等于每个外部研究工作区都被强制执行。
